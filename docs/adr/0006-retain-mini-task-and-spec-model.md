# Retain Accelerator Mini's task and living specification model

The toolset retains temporary task workspaces under `tasks/TASK-NNN/` and permanent living specifications under `specs/`. It does not adopt the Frontend Starter Accelerator's `ai/context`, G0 briefs, governance task types, memory synchronization, or controlled-delivery reports, keeping documentation aligned with the manual one-command-one-agent flow.

## Consequences

- Task artifacts may be removed after their implementation is complete.
- Architecture, API integration, UI design, and implementation truth must be maintained in living specifications.
- Frontend adaptation changes the contents and names of relevant specs without introducing a second memory system.
