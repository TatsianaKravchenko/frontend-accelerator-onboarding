# Make UI design appropriate to product context

UI Designer preserves an existing design system and chooses interface density, expression, typography, motion, and visual character from the product, audience, and usage pattern rather than enforcing Accelerator Mini's globally bold aesthetic. Accessibility, hierarchy, responsive behavior, and usability remain universal, while brand and visual-system decisions come from the Project Ruleset or explicit human selection among proposed directions.

## Consequences

- Operational tools may be quiet and dense; branded or consumer experiences may be more expressive.
- The toolset cannot globally ban common fonts, flat backgrounds, conventional grids, or restrained motion.
- When no design direction exists, UI Designer proposes alternatives and waits for a human choice rather than silently creating a project style.
