# Frontend Accelerator Training

This directory contains all training tasks and assessment material. It is separate from the toolset's installation, runtime, agent, skill, and ruleset documentation.

If a mentor did not explicitly assign the **Advanced / Production Assessment**, complete only the **Basic Accelerator Onboarding**.

## Using A Training Package

Copy only the assigned package directory into the target project root and keep that package's directory name unchanged. Do not copy the parent `training/` directory or the other track.

## Choose One Track

### Default: Basic Accelerator Onboarding

Use [`frontend-accelerator-onboarding/README.md`](frontend-accelerator-onboarding/README.md).

Choose this track when the goal is to learn how to:

- select accelerator roles manually;
- write a bounded prompt for each selected role;
- review each role's output;
- decide the next action without automatic role chaining;
- complete one small implementation, review, and verification loop;
- record honest, concise evidence.

The result is binary: **Passed** or **Repeat a stage**. Production-level polish is not required.

### Assigned Only: Advanced / Production Assessment

Use [`frontend-accelerator-assessment/README.md`](frontend-accelerator-assessment/README.md) only when a mentor explicitly assigns it.

This track evaluates both accelerator use and production-minded frontend quality. It includes a 100-point rubric, section minimums, assessment blockers, broader browser evidence, and stricter product requirements. It is not a prerequisite for completing Basic Accelerator Onboarding.

## Rule For Mentors

Send the participant a direct link to the selected track's `README.md`. Do not ask a new participant to choose between the tracks.
